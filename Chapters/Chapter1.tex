\section{Objective}

\subsection{General objective}

The general objective of this project is to study related state-of-the-art technologies and then apply them to design, develop and evaluate an Intelligent System which supports Predictive Maintenance of Industrial Machines. This work can be classified as a Practical Application Work (“Trabajo de Aplicación Práctica”)

This intelligent system should be a concrete software and must work with at least one case study.

The data-driven approach for development of the intelligent Predictive Maintenance system should be general and scalable. During the development of this work, these questions can be answered:

\begin{itemize}
\item Can industrial machine failures be predicted before they happen using historical and new machine data?
\item Is there a general and scalable approach of data-driven predictive maintenance for different types of industrial machine?
\item Can the intelligent Predictive Maintenance solution be deployed and used effectively in real life as a software, but not as machine learning models created and used by data scientists?
\end{itemize}

Because this work focuses on industrial environments, its primary scope of maintenance is Industrial Machines, although its results can also be applied for home, transportation, IT… devices.
